# Saraf Analyzer Pro

نسخه حرفه‌ای تحلیل‌گر بازار برای Android.

## امکانات
- داده OHLC واقعی نوبیتکس برای بازارهای ریالی/کریپتویی
- تحلیل MA20/50/200، RSI، MACD، Bollinger، ATR و حجم
- تحلیل چندتایم‌فریمی
- ماکرو: طلا، DXY، بازده 10Y، VIX و BTC از Yahoo Finance
- امتیاز ترکیبی و فیلتر عدم معامله
- مدیریت سرمایه و محاسبه R/R و حجم
- تاریخچه محلی سیگنال‌ها
- Native Android network bridge برای دور زدن محدودیت CORS مرورگر

## ساخت APK
پروژه را در Android Studio باز کنید و Build > Build APK(s) را اجرا کنید.
حداقل Android 7.0 (API 24).

توجه: نسخه فعلی سفارش‌گذاری خودکار ندارد و کلید API خصوصی ذخیره نمی‌کند.
